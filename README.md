# aws-security-lab
Infrastructure as Code (IaC) project built with Terraform to provision a highly available web application infrastructure on AWS.

The project demonstrates AWS networking, EC2, IAM, S3, Security Groups, Application Load Balancer, private/public subnets, and Terraform best practices.
Project Objectives
The main objectives of this project are to demonstrate:
Infrastructure as Code with Terraform
AWS VPC networking
Public and private subnets
Multiple Availability Zones
Internet Gateway
Route tables
Security Groups
EC2 instances
IAM roles and instance profiles
IAM-based access control
S3 storage
Application Load Balancer
Target groups
Health checks
High availability
Least-privilege security principles
Resource tagging
Terraform variables and outputs
